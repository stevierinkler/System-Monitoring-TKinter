System-Monitoring Tool

The purpose of this tool is to observe your Computer in realtime.
Similar to Task Manager but with Warning Notifications especially for RAM and CPU.

The Tool itself currently observes your : CPU Usage, RAM Usage, Network Traffic (Bytes sent and received), Disk Storage.

The Installation currently runs as a Python script that opens a GUI made with TKinter.
At a later stage of the Programm it will Transition to an .exe for an easier use of the tool and a better UX.

My Motivation behind creating this tool, is to build up a fundamental knowledge for a connection between IT and OT.
As an Electrician i already got experience on the OT side. The goal now is to connect my OT experience with the gained IT knowledge
to further anticipate towards Industry 4.0 and Automation.
